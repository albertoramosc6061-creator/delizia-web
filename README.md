# Delizia Bolivia — Sistema de Gestión

Sistema de gestión empresarial para **Delizia Bolivia**, empresa láctea boliviana.

## 🚀 Cómo usar

Abre `login.html` en tu navegador. No requiere servidor.

## 🔐 Cuentas de demostración

| Rol | Usuario | Contraseña |
|-----|---------|-----------|
| Administrador | alexander@delizia.bo | admin123 |
| Empleado | alan@delizia.bo | emp123 |
| Cliente | Crea tu cuenta desde el login | — |

## 📋 Funcionalidades

- **Admin**: Dashboard con KPIs, gestión de empleados, clientes, proveedores, productos, categorías, pedidos, bitácora y reportes.
- **Empleado**: Panel de pedidos (actualizar estado), catálogo y lista de clientes.
- **Cliente**: Catálogo, realizar pedidos, historial y perfil.

## 🛠 Tecnologías

- HTML5 + CSS3 (Vanilla)
- JavaScript (ES6+)
- `localStorage` como base de datos local
